# Personal Media Saver

현재 탭의 `<video>`·`<audio>` 요소와 미디어 링크를 찾고, 사용자가 선택한 사이트에서 네트워크 응답을 추가로 살펴보는 개인용 Chrome 확장입니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 개발자 모드를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 선택합니다.
4. 이 폴더를 선택합니다.

## 동작 범위

- 일반 MP4·WebM·MP3 등의 직접 파일 다운로드
- HLS `.m3u8` 재생목록과 비암호화 조각 저장
- HLS 변형 재생목록은 대역폭이 가장 높은 항목을 선택
- 탐지 요청은 권한을 허용한 사이트 범위로만 감지하고 기기 로컬에 보관
- DRM·암호화된 HLS, DASH, Blob URL, 바이트 범위 HLS, 별도 오디오 HLS는 지원하지 않음
- HLS 조각은 받는 즉시 확장 내부 저장소(OPFS)에 기록하므로 길이·용량 제한이 없음 (저장 중 일시적으로 파일 크기만큼 디스크 추가 사용)
- 다른 도메인에서 조각을 가져오는 HLS는 지원하지 않음
- 사이트별 권한은 `이 사이트에서 계속 찾기` 또는 HLS 저장을 눌렀을 때 요청

이 도구는 사용 권한이 있는 미디어에만 사용하도록 설계했습니다. 원본 확장 프로그램의 코드, 아이콘, 브랜드 자산은 포함하지 않습니다.
